# Hi, I’m ropepop.

I build software for the devices I use every day. On iPhone, I’ve been exploring how to browse music in one service and play it in another. On macOS, I’ve been looking at how a tool can recognize a permission dialog and tell whether it closed.

## Selected work

| Project | What you’ll find |
| --- | --- |
| [Permission Approver](https://github.com/ropepop/permission-approver) | A macOS automation case study on recognizing permission dialogs using on-screen text. |
| [Multimusic](https://github.com/ropepop/multimusic) | Two iPhone apps that match tracks found through Spotify or YouTube Music to recordings on Apple Music. |
| [Latvian court calendar parser](https://github.com/ropepop/cases-parser) | A parser for hearing schedules exported from Latvia’s court calendar. |

For a look at how I run these kinds of systems, explore my [server operations](https://github.com/ropepop/public-ops) and [Pixel phone runtime](https://github.com/ropepop/pixel-phone).
